<h1>Ghost Maze</h1>
A 3D Maze Game which follows the ghost as the player. The ghost has to be guided around the maze to collect sufficient coins in order to advance a level all while escaping the enemy which continously follows it throughtout the map.
There are a total of two levels within this game.
